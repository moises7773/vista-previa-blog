# Frontend Mentor - Solución para la tarjeta de vista previa de un blog

Esta es una solución al [desafío de tarjeta de vista previa de un blog en Frontend Mentor](https://www.frontendmentor.io/challenges/blog-preview-card-ckPaj01IcS). Los desafíos de Frontend Mentor te ayudan a mejorar tus habilidades de programación mediante la creación de proyectos realistas.

### El desafío

Los usuarios deben poder:

- Ver los estados de *hover* (al pasar el cursor) y *focus* (al enfocar) en todos los elementos interactivos de la página.

## Lo que aprendí

- Cómo inspeccionar diseños en Figma para identificar dimensiones, espaciados, tipografías, colores y sombras.
- Cómo implementar sombras personalizadas utilizando la propiedad `box-shadow`.
- Cómo controlar las dimensiones de los elementos mediante `width`, `min-width` y `max-width`.
- Cómo utilizar `fit-content` para adaptar el ancho de un elemento a su contenido.
- Cómo crear diseños fluidos sin utilizar media queries.
- Cómo utilizar las funciones CSS `clamp()` y `calc()` para crear dimensiones y tamaños de fuente adaptables.
- Cómo interpolar tamaños de tipografía entre diseños móviles y de escritorio.
- Cómo utilizar Flexbox para organizar y distribuir elementos.
## Desarrollo continuo

En futuros proyectos quiero seguir profundizando en el diseño responsivo, especialmente en la creación de interfaces que se adapten correctamente a diferentes tamaños de pantalla sin depender excesivamente de media queries.

Me gustaría perfeccionar el uso de funciones CSS como clamp(), min(), max() y calc() para conseguir diseños más fluidos y flexibles.

También quiero mejorar mi comprensión de Flexbox y CSS Grid para desarrollar distribuciones que se adapten dinámicamente al espacio disponible, así como aprender a identificar cuándo utilizar cada técnica para conseguir una mejor experiencia en distintos dispositivos.
